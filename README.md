# DiAnna Guide

PWA-довідник для гостей **DiAnna Medical & SPA**.

## Стек

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS
- [Vercel KV](https://vercel.com/docs/storage/vercel-kv) — зберігання кнопок другого екрану, тексту послуг і тексту правил, керованих через адмінку
- PWA: `manifest.json` + мінімальний service worker (`public/sw.js`) + кнопка "Встановити застосунок"

## Контент

Кнопки другого екрану, текст акордеону "Послуги" і текст правил проживання
редагуються через адмінку **`/admin`** (див. нижче) і зберігаються у Vercel
KV — саме звідти їх читає публічна сторінка. Файл
[`src/config/config.ts`](./src/config/config.ts) містить лише СТАРТОВІ
дані/фолбек на випадок, якщо KV ще порожній, а також речі, які через
адмінку не редагуються (назва застосунку, соцмережі, контакт менеджера).

## Адмінка (`/admin`)

Захищена паролем через env-змінну `ADMIN_PASSWORD` (проста httpOnly-cookie
авторизація, без окремої auth-системи). Дозволяє:

- редагувати назву/посилання/акцентність кожної кнопки, видаляти й додавати нові, міняти порядок (drag або стрілки ↑/↓);
- редагувати текст послуг акордеону (по одному пункту на рядок);
- редагувати повний текст правил проживання.

Зміни з'являються на публічній сторінці одразу після збереження.

## Змінні середовища

Скопіюй [`.env.example`](./.env.example) у `.env.local` і заповни:

| Змінна | Призначення |
| --- | --- |
| `ADMIN_PASSWORD` | Пароль для входу в `/admin`. Постав власний через Vercel env variables — приклад у `.env.example` не для продакшену. |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | З'являються автоматично після підключення Vercel KV (Storage → KV) у Vercel Dashboard. Без них застосунок працює на тимчасовому сховищі в пам'яті процесу — зручно для локальної розробки, але дані не зберігаються між перезапусками (див. `src/lib/kv.ts`). |
